💻 ns-3 Command Cheat Sheet

A structured quick-reference guide to configure, build, run, and debug your simulation scripts.

Configure

Configure CMake (Debug)

Configure CMake to compile with logging, tests, and debugging assertions enabled. Crucial for development.

./ns3 configure --enable-examples --enable-tests --build-profile=debug
Configure

Configure CMake (Optimized)

Configure CMake to strip debug symbols and compile with optimization flags. Speed up large simulation sweeps by 5x-10x.

./ns3 configure --build-profile=optimized
Build

Build the Project

Compile the whole project or incrementally build changes. Scratch scripts compile automatically on build.

./ns3 build
Run

Run Scratch Executable

Run a compiled script located in your scratch directory. You do not need to append the `.cc` extension.

./ns3 run scratch/aerowlan_exercises/hello-ns3
Run

Run with Command-Line Args

Pass custom arguments to your script using a double-dash `--` separator at runtime.

./ns3 run "scratch/aerowlan_exercises/simple-wifi --distance=15.0 --pcap=1"
Debug

Enable Logging (NS_LOG)

Enable verbose execution logs from specific components using the environment variable `NS_LOG`.

export NS_LOG="UdpEchoClientApplication=level_all:WifiPhy=level_info"
Debug

Clear Logging Configuration

Unset the logging configuration to return to default stdout behavior and silence verbose simulation output.

unset NS_LOG
Trace

Inspect PCAP packet traces

Read generated simulation packet captures directly in your Linux terminal using `tcpdump`.

tcpdump -nn -tt -r simple-wifi-0-0.pcap
Clean

Clean Build Cache

Delete compilation files and reset the CMake cache. Useful if headers are missing or linking conflicts arise.

./ns3 clean
