Essential ns-3 & Linux Commands

Command Action Purpose
./ns3 configure --enable-examples --enable-tests Configuration Prepares the CMake build directory with examples/tests enabled.
./ns3 build Compilation Compiles any new changes in scratch or src directories.
./ns3 run <script-name> Execution Runs a compiled executable from the scratch folder.
NS_LOG="WifiPhy:WifiMac" ./ns3 run <script> Debugging logs Enables detailed console logging for WifiPhy and WifiMac components.
./ns3 run <script> -- --pcap=1 Packet capture Triggers packet capture file generation (.pcap) on active netdevices.
